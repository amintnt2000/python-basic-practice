# 🏦 پروژه‌ی اول: Bank Account System | سیستم حساب بانکی

## 📋 توضیحات

دو کلاس برای مدیریت حساب بانکی:

- **`BankAccount`**: کلاس پایه برای مدیریت یک حساب بانکی ساده (واریز، برداشت، نمایش موجودی)
- **`SavingAccount`**: کلاس فرزند که از `BankAccount` ارث‌بری می‌کند و ویژگی سود پس‌انداز و جریمه‌ی برداشت را اضافه می‌کند

## 🧩 کلاس `BankAccount`

| متد/ویژگی | توضیح |
|---|---|
| `__init__(owner, balance=0)` | ساخت حساب با نام صاحب و موجودی اولیه |
| `balance` (property) | خواندن یا تغییر موجودی (مقدار منفی مجاز نیست) |
| `deposit(amount)` | واریز مبلغ به حساب |
| `withdraw(amount)` | برداشت مبلغ (در صورت کافی نبودن موجودی، پیام خطا) |
| `get_balance()` | دریافت موجودی فعلی |
| `__str__()` | نمایش خوانا از حساب |

### مثال

```python
acc = BankAccount("امین", 1000)
acc.deposit(500)
acc.withdraw(200)
print(acc)
# خروجی: حساب امین با موجودی 1300
```

## 💰 کلاس `SavingAccount` (ارث‌بر از `BankAccount`)

| متد | توضیح |
|---|---|
| `__init__(owner, balance, interest_rate)` | ساخت حساب پس‌انداز با نرخ سود مشخص |
| `add_interest()` | افزودن سود به موجودی |
| `withdraw(amount)` | برداشت با جریمه‌ی ۱۰٪ (بازنویسی متد پدر) |
| `__str__()` | نمایش موجودی به همراه نرخ سود |

### مثال

```python
saving = SavingAccount("امین", 1000, 0.05)
saving.add_interest()
saving.withdraw(100)
print(saving)
```

## 🔑 مفاهیم کلیدی

- وراثت (Inheritance) و `super()`
- Property / Setter برای کنترل دسترسی به `balance`
- Override کردن متد `withdraw`

## ⚠️ نکته

در `balance.setter`، مقدار منفی رد می‌شود ولی فقط پیام چاپ می‌شود؛ بهتره به‌جای `print` از `raise ValueError` استفاده بشه.

# 📚 پروژه‌ی دوم: Library System | سیستم مدیریت کتابخانه

## 📋 توضیحات

سه کلاس برای شبیه‌سازی یک کتابخانه:

- **`Book`**: مدیریت یک کتاب فیزیکی و تعداد نسخه‌های موجود
- **`EBook`**: کلاس فرزند برای کتاب الکترونیکی (نسخه‌ی نامحدود)
- **`Library`**: نگه‌داری لیست کتاب‌ها و نمایش همه‌ی آن‌ها

## 🧩 کلاس `Book`

| متد/ویژگی | توضیح |
|---|---|
| `__init__(title, auther, total_copies)` | ساخت کتاب با عنوان، نویسنده و تعداد کل نسخه‌ها |
| `available_copies` (property) | تعداد نسخه‌های در دسترس |
| `borrow()` | امانت گرفتن یک نسخه (در صورت نبود نسخه، پیام خطا) |
| `return_book()` | برگرداندن نسخه به کتابخانه |
| `__str__()` | نمایش عنوان، نویسنده و تعداد نسخه‌های موجود |

### مثال

```python
b = Book("هابیت", "تالکین", 3)
b.borrow()
print(b)
# خروجی: title: هابیت, auther: تالکین, available copies: 2 of 3
```

## 📱 کلاس `EBook` (ارث‌بر از `Book`)

| متد | توضیح |
|---|---|
| `__init__(title, auther)` | ساخت کتاب الکترونیکی با نسخه‌ی نامحدود (`float("inf")`) |
| `borrow()` (override) | به‌جای کم کردن موجودی، پیام "دانلود موفق" چاپ می‌کند |
| `__str__()` | نمایش مخصوص کتاب الکترونیکی |

### مثال

```python
e = EBook("۱۹۸۴", "جورج اورول")
e.borrow()
# خروجی: Download completed successfully
```

## 🏛️ کلاس `Library`

| متد | توضیح |
|---|---|
| `__init__()` | ساخت لیست خالی از کتاب‌ها |
| `add_books(book)` | اضافه کردن یک کتاب (فیزیکی یا الکترونیکی) به لیست |
| `show_all_books()` | نمایش تمام کتاب‌های موجود در کتابخانه |

### مثال

```python
lib = Library()
lib.add_books(Book("هابیت", "تالکین", 3))
lib.add_books(EBook("۱۹۸۴", "جورج اورول"))
lib.show_all_books()
```

## 🔑 مفاهیم کلیدی

- وراثت و بازنویسی متد (`EBook` رفتار `borrow` را کاملاً عوض می‌کند)
- استفاده از `float("inf")` برای نمایش نسخه‌ی نامحدود
- Composition: کلاس `Library` نمونه‌هایی از `Book` را نگه می‌دارد
