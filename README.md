# 👥 Users API

یک API ساده به زبان پایتون با فریم‌ورک Flask برای مدیریت کاربران، به همراه یک اسکریپت کلاینت برای تست کردن API.
اطلاعات کاربران فعلاً در حافظه (یک لیست ساده) نگه‌داری می‌شه.

## ✨ امکانات

- 📋 نمایش لیست تمام کاربران
- 🔍 دریافت اطلاعات یک کاربر بر اساس آی‌دی
- ➕ افزودن کاربر جدید (با آی‌دی خودکار) و ذخیره‌ی اون توی لیست
- 🧪 اسکریپت تست برای ارسال درخواست POST و بررسی خطاهای اتصال

## 🛠 پیش‌نیازها

- Python 3.x
- کتابخانه‌ی Flask (برای سرور)
- کتابخانه‌ی requests (برای اسکریپت تست)

```bash
pip install flask requests
```

## 🚀 نحوه اجرا

### ۱. اجرای سرور

```bash
python app.py
```

سرور روی آدرس زیر بالا می‌آد:

```
http://127.0.0.1:5000
```

### ۲. اجرای اسکریپت تست (در یک ترمینال جدید، وقتی سرور روشنه)

```bash
python client.py
```

این اسکریپت یک کاربر جدید (`max`) رو با درخواست POST به سرور می‌فرسته و نتیجه رو چاپ می‌کنه. اگه سرور روشن نباشه، پیام `Connection Error` نشون داده می‌شه؛ اگه سرور کند جواب بده (بیشتر از ۵ ثانیه)، پیام `Request timed out` نشون داده می‌شه.

## 📡 Endpoint های سرور

### `GET /users`
لیست همه‌ی کاربران رو برمی‌گردونه.

```json
[
  {"id": 1, "name": "amin", "email": "amin@gmail.com"},
  {"id": 2, "name": "sara", "email": "sara@gmail.com"}
]
```

### `GET /users/<user_id>`
یک کاربر خاص رو با آی‌دی برمی‌گردونه.

**نمونه:** `GET /users/1`
```json
{"id": 1, "name": "amin", "email": "amin@gmail.com"}
```

اگه کاربر پیدا نشه → status `404`:
```json
{"error": "user not found"}
```

### `POST /users`
یک کاربر جدید می‌سازه، آی‌دی رو به‌صورت خودکار (بزرگ‌ترین آی‌دی موجود + ۱) بهش می‌ده و به لیست کاربران اضافه‌ش می‌کنه.

**بدنه‌ی درخواست:**
```json
{"name": "max", "email": "max@gmail.com"}
```

**پاسخ (status 201):**
```json
{"name": "max", "email": "max@gmail.com", "id": 3}
```

## ⚠️ نکات فنی

- اطلاعات کاربران فقط در حافظه‌ی برنامه نگه‌داری می‌شه؛ با ری‌استارت سرور از بین می‌ره.
- قبل از اجرای `client.py` حتماً باید `app.py` روشن باشه، وگرنه `ConnectionError` می‌گیری.

## 🔮 ایده برای توسعه‌های بعدی

- اضافه کردن قابلیت ویرایش و حذف کاربر (PUT / DELETE)
- اعتبارسنجی ورودی‌ها (مثل فرمت ایمیل و اجباری بودن فیلدها)
- ذخیره‌سازی دائمی روی فایل JSON یا دیتابیس
- گسترش اسکریپت تست برای پوشش دادن همه‌ی endpoint ها (GET همه، GET تکی، خطاها)
