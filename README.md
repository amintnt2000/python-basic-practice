# 📞 Phone Book (دفترچه تلفن)

یک پروژه‌ی ساده به زبان پایتون برای مدیریت دفترچه تلفن از طریق ترمینال.
اطلاعات مخاطبین در یک فایل JSON ذخیره می‌شه تا بعد از بستن برنامه هم از بین نره.

## ✨ امکانات

- ➕ افزودن مخاطب جدید (با بررسی تکراری بودن نام)
- 🔍 جستجوی مخاطب بر اساس نام
- 🗑️ حذف مخاطب
- 📋 نمایش تمام مخاطبین
- 💾 ذخیره‌سازی خودکار در فایل `contacts.json`

## 🛠 پیش‌نیازها

- Python 3.x

هیچ کتابخانه‌ی خارجی‌ای لازم نیست، فقط از ماژول‌های استاندارد `json` و `os` استفاده شده.

## 🚀 نحوه اجرا

```bash
python phone_book.py
```

بعد از اجرا، یک منو نمایش داده می‌شه:

```
What do you want to do?
a) Add contact
s) Search contact
d) Delete contact
c) Show all
x) Exit
```

## 📁 ساختار فایل‌ها

```
.
├── phone_book.py     # کد اصلی برنامه
├── contacts.json     # فایل ذخیره‌سازی مخاطبین (خودکار ساخته می‌شه)
└── README.md
```

## 📝 نکات فنی

- شماره تلفن‌ها به صورت عدد صحیح (`int`) ذخیره می‌شن.
- در صورت خراب بودن یا خالی بودن فایل JSON، برنامه به جای کرش کردن یک دیکشنری خالی برمی‌گردونه.
- ذخیره‌سازی با `ensure_ascii=False` انجام می‌شه تا حروف فارسی درست نمایش داده بشن.

## 🔮 ایده برای توسعه‌های بعدی

- افزودن اعتبارسنجی برای فرمت شماره تلفن
- امکان ویرایش مستقیم اطلاعات مخاطب
- خروجی گرفتن به فرمت CSV یا Excel
- رابط گرافیکی (GUI) با Tkinter
