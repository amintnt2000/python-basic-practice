# 🤖 File Robot | ربات دسته‌بندی فایل‌ها

اسکریپتی ساده و کاربردی برای مرتب‌سازی خودکار فایل‌های داخل یک پوشه، بر اساس نوع (پسوند) فایل.

---

## 📋 توضیحات

این برنامه یک مسیر پوشه از کاربر می‌گیرد، تمام فایل‌های داخل آن را بررسی می‌کند و بر اساس پسوندشان، هرکدام را داخل زیرپوشه‌ی مناسب جابه‌جا می‌کند. اگر پسوند فایلی در دسته‌بندی‌های تعریف‌شده نباشد، در پوشه‌ی `Others` قرار می‌گیرد.

---

## ⚙️ نحوه‌ی کارکرد

1. مسیر پوشه از کاربر گرفته می‌شود.
2. لیست فایل‌های داخل آن پوشه خوانده می‌شود.
3. برای هر فایل، پسوندش استخراج و با دیکشنری `categories` مقایسه می‌شود.
4. پوشه‌ی دسته‌بندی مربوطه (در صورت نبودن) ساخته می‌شود.
5. فایل به پوشه‌ی مقصد منتقل می‌شود.

---

## 🗂️ دسته‌بندی‌ها

| پسوند | دسته |
|---|---|
| `.jpg` `.jpeg` `.png` | 🖼️ Images |
| `.pdf` | 📕 PDFs |
| `.txt` `.docx` | 📄 Text |
| `.mp3` | 🎵 Audio |
| `.mp4` | 🎬 Video |
| سایر پسوندها | 📦 Others |

## 💡 ایده‌های آینده

- [ ] پشتیبانی از دسته‌بندی بازگشتی (زیرپوشه‌ها هم بررسی بشن)
- [ ] لاگ گرفتن از فایل‌های جابه‌جا شده در یک فایل متنی
- [ ] دریافت دسته‌بندی‌ها از یک فایل `config.json` به‌جای هاردکد بودن در کد
- [ ] اضافه کردن رابط خط فرمان (CLI) با آرگومان‌ها به‌جای `input()`
- [ ] هندل کردن خطا برای مسیر نامعتبر یا عدم دسترسی
