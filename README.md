# Simple Agent 🤖

یک ایجنت ساده‌ی هوش مصنوعی که با مدل‌های زبانی لوکال (از طریق Ollama) کار می‌کنه و به دو ابزار (Tool) دسترسی داره:

- **Calculator** — انجام محاسبات ریاضی
- **Wikipedia Search** — جستجوی اطلاعات عمومی از ویکی‌پدیا (با ترجمه‌ی خودکار به فارسی)

## ویژگی‌ها

- تشخیص خودکار نیاز به استفاده از ابزار، بر اساس سوال کاربر
- اجرای واقعی توابع پایتون (نه فقط شبیه‌سازی)
- ترجمه‌ی خودکار نتایج انگلیسی به فارسی روان
- اجرای کاملاً لوکال و رایگان، بدون نیاز به API خارجی یا هزینه

## پیش‌نیازها

- Python 3.10 یا بالاتر
- [Ollama](https://ollama.com) نصب‌شده و در حال اجرا
- مدل `llama3.1:8b` دانلود‌شده روی Ollama:
  ```bash
  ollama pull llama3.1:8b
  ```

۱. مطمئن شو Ollama در حال اجراست (در پس‌زمینه یا با دستور `ollama serve`)

۲. فایل `simple_agent.py` رو اجرا کن:
```bash

```

## نحوه‌ی استفاده در کد

```python
from simple_agent import ask_agent

print(ask_agent("حاصل 234 ضرب در 17 چقدره؟"))
print(ask_agent("آلبرت اینشتین کیه؟"))
print(ask_agent("سلام، حالت چطوره؟"))
```


## نحوه‌ی کارکرد (معماری)

۱. پیام کاربر همراه با یک **system prompt** (که توضیح می‌ده چه ابزارهایی موجوده و چه فرمتی باید برگردونده بشه) به مدل ارسال می‌شه.

۲. مدل یا:
   - یک شیء JSON با فرمت `{"tool": "...", "...": "..."}` برمی‌گردونه (یعنی تشخیص داده به ابزار نیاز داره)، یا
   - مستقیماً به زبان طبیعی جواب می‌ده (وقتی نیازی به ابزار نیست)

۳. اگه خروجی JSON معتبر بود:
   - نام ابزار (`calculator` یا `wikipedia_search`) بررسی می‌شه
   - تابع پایتون مربوطه با پارامترهای داده‌شده اجرا می‌شه
   - در مورد ویکی‌پدیا، نتیجه (که به انگلیسیه) با یک فراخوانی دیگه به مدل، به فارسی ترجمه می‌شه

۴. نتیجه‌ی نهایی به کاربر برگردونده می‌شه

## محدودیت‌های شناخته‌شده

- مدل `llama3.1:8b` به‌صورت رسمی از پارامتر `tools=` در OpenAI API پشتیبانی نمی‌کنه، به همین دلیل تشخیص ابزار به‌صورت دستی (با پارس کردن JSON از متن خروجی) انجام می‌شه، نه با مکانیزم استاندارد `tool_calls`.
- محاسبات با `eval()` انجام می‌شه که در محیط تولید (production) امن نیست؛ برای این پروژه‌ی آموزشی مشکلی نداره.
- ترجمه‌ها گاهی ممکنه کلمات یا اسامی خاص رو به‌درستی ترجمه نکنن (محدودیت مدل‌های کوچیک).
- جستجوی ویکی‌پدیا فقط با عنوان دقیق (به انگلیسی) کار می‌کنه؛ برای عناوین مبهم ممکنه نتیجه‌ای پیدا نکنه.

## قدم‌های بعدی پیشنهادی

- اضافه کردن ابزار سوم (مثلاً آب‌وهوا یا جستجوی وب)
- تبدیل به یک Agent Loop واقعی که بتونه چند ابزار رو پشت‌سرهم و در چند مرحله استفاده کنه
- اضافه کردن حافظه‌ی مکالمه بین چند پیام
